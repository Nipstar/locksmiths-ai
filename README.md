# AI Receptionist for Locksmiths

UK-wide AI receptionist + 24/7 AI answering service for locksmith services. Built for sole trader and mobile locksmiths, 24/7 emergency locksmiths, auto locksmiths, commercial/access-control locksmiths and multi-van firms.

**Live domain:** aireceptionistforlocksmiths.co.uk
**Part of:** Antek Automation network (locksmith vertical spoke off aivoiceagentreceptionist.co.uk hub)
**Tech:** Static HTML, no build step
